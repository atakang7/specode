# Contributing

1. Create a branch from `main` and keep the change scoped.
2. For runner changes, run the [runner checks](docs/how-to/check-runner.md).
3. Include the changed behavior and verification commands in the pull request.
4. Record user-visible changes in [CHANGELOG.md](CHANGELOG.md).

The `core`, `cli`, and `web` packages currently have no automated test scripts.
